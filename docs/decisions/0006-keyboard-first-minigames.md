# ADR 0006 — Mini-games are keyboard-first; mouse is optional

**Status:** accepted · 2026-09-04

## Decision
Every mini-game is fully playable with arrows/WASD, Space, and one of `1-2-3` or `Q/E`.
Mouse drag is an alternative input for the same actions, never a required one.

## Why
Eight people on laptops with trackpads. Drag-and-drop on a trackpad while also steering an
avatar is miserable. Keyboard-only keeps every mini-game ≤ 3 inputs and readable.

## Rejected
- **Mouse-first drag/drop** (the handoff's lean). Revisit if a mini-game genuinely needs it.
