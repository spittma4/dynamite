# DYNAMITE MVP (M0 + M1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable MVP — Boom Powder → Assembly → Dock on one line, 3–6 players in a browser, with the pile, hands-full, throw/catch, the explosion, a shift clock and order book, and an end-of-day report card — ready for a first playtest.

**Architecture:** Laravel 13 (Livewire + Flux) owns accounts, factories, levels, runs and the game page; a Node 22 + Colyseus 0.18 process runs the authoritative 20 Hz simulation per factory room; a Phaser 4 client renders state and sends input; a `shared/` TypeScript package holds the schema, messages, config types and the pure sim rules both sides use. Three HMAC-signed internal calls join Laravel and Node.

**Tech Stack:** PHP 8.4 · Laravel 13.30 · Livewire 4.4 · Flux 2.18 (free) · Pest · Postgres 18 (Herd) · Node 22 · Colyseus 0.18.5 · @colyseus/schema 5 · @colyseus/sdk 0.18 · Phaser 4.2.1 · TypeScript · Vite · vitest

**Spec:** `docs/features/00-contracts.md` (binding) and `docs/features/F01`–`F12` (one per feature, each with its own acceptance checklist). Design rationale: `docs/00`–`19`, `docs/decisions/`.

## Global Constraints

- Player range 3–10; **M1 targets one line, 3–6** (`players.min = 3`).
- Server tick **20 Hz**; tile **32 px**; speed **4 tiles/s**; carrying ×0.8.
- Every timing window is in **milliseconds**, from config: no OK threshold under **±100 ms**, no Perfect under **±45 ms**.
- Mini-games: ≤ 3 inputs on WASD/arrows + Space + E (Q/E for sticky selectors); one gesture per station; the server judges every input.
- Consequences are never random: no random fumbles, no random loss. Sparks come from acts; the explosion always follows the pile, the beacon, and a 6 s fuse.
- Output lands in the operator's hands; auto-shelves if there's room (ADR 0012).
- No commits are made by agents (the repo owner commits). Never weaken or skip a test to make it pass.
- Copy (joke lines) lives in `config/game/copy.json`. Numbers a designer might tune live in level JSON.
- Laravel: `declare(strict_types=1)`, Actions in `app/Actions`, Pest, Pint. TS: strict, explicit return types, no `any`.

## MVP-ready checklist (the goal condition)

- [ ] Sign up, sign in, create a factory, share its join code, a second account joins.
- [ ] Both players enter the factory page; the game connects; both see each other walk (M0).
- [ ] Owner starts the day; the clock runs; the order book shows; a truck arrives on cadence.
- [ ] The Slammer: mash → charge → release makes a keg with visible quality; Heat changes the window; late release throws a spark; a 4th press spills; shelf full → hands full; E drops at your feet; combo counter shows in-world.
- [ ] The Jig: seat (dents visible), pour by keg quality, knots on lanes, ratchet crimp → a stick; PRIME STICK flash; B can pick/fetch/toss into the cradle.
- [ ] The Dock: sticks set on ramp tiles, shove on the beep, stall on miss, tailgate slam, partial truck → returns.
- [ ] Throw/catch between players with Perfect/OK; bump drops; keg knock-over → spill; stick fizzle 30%.
- [ ] Hazards: fuel + spark → fuse → stomp works; chain → Whoops; ≥ 10 → EXPLODED ends the day (setback mode on Level 1); DANGER beacon at 50%; hot potato into the Blast Bin → NICE SAVE.
- [ ] Day ends on the book or the clock; report card shows grade + P&L + the individual-vs-factory joke; run stored; factory day advances on C+.
- [ ] Levels 1–4 + Sandbox selectable; Sandbox has no timer and the debug overlay on.
- [ ] Reconnect within 30 s keeps your avatar. Three-player minimum enforced in the lobby.
- [ ] `composer test`, `npm test` (shared), `game-server` tests all green; `npm run build` clean.
- [ ] `docs/features/F01`–`F12` acceptance boxes ticked; `docs/PLAYTEST.md` written (how to run, what to watch for, the three sentences we hope to hear).

## Verification protocol (every wave)

1. Unit: `composer test` (Laravel), `cd shared && npx vitest run`, `cd game-server && npx vitest run`.
2. Build: `npm run build` at the root (Vite, both entries).
3. In-app: game-server running (`npm run dev` in `game-server/`), Laravel served by Herd, two headless Chrome pages via `chrome-devtools-axi` logged in as two seeded users, joined to one factory; screenshots saved to the scratchpad and inspected.
4. Feature doc boxes ticked only after step 3 shows it.
